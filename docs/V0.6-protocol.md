# PARADOX LAB V0.6 protocol

Provider-neutral benchmark for finite classical Boolean fixed-point systems Xi = expression_i.

1. Compute the exact satisfiability oracle by exhaustive enumeration (up to 12 variables).
2. Ask the model for SAT plus a complete assignment, or UNSAT plus a zero-based unsatisfiable subset of rules.
3. Validate assignments and conflict subsets mechanically.
4. Repeat identical prompts and report per-error rates, latency, model/version, decoding settings and token budget.

Error labels: FORMAT, FALSE_UNSAT, MISSED_UNSAT, INCOMPLETE_ASSIGNMENT, INVALID_ASSIGNMENT, INVALID_CORE, CORE_NOT_UNSAT. Provider errors must be tracked separately from model errors.

The oracle only certifies the encoded Boolean semantics. A deletion-minimal core is not necessarily minimum-cardinality. Repeated failures on one item do not establish a general model defect. Keep API keys server-side; never embed credentials in browser code. This evaluates final outputs, not hidden reasoning.

Adapter contract for a future runner: async function(prompt, context) returning a JSON string or parsed object. Network transport and credentials are deliberately outside this engine.
