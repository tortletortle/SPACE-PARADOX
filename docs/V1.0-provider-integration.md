# PARADOX LAB V1.0 — provider connection

The V1.0 adapter uses an OpenAI-compatible Chat Completions endpoint. It runs server-side in Node.js and reads credentials from environment variables.

## Configuration
Set `PARADOX_API_BASE_URL`, `PARADOX_API_KEY`, and `PARADOX_MODEL`. Defaults target the OpenAI-compatible `/chat/completions` path; for other providers, configure their compatible base URL and model ID.

## Run
Use Node.js 18+:
```sh
node scripts/run-model-evaluation.cjs
```
The runner writes JSON evidence into `reports/`. Never expose the adapter to an untrusted browser or commit API keys. The included tests mock fetch and make no network requests.

## Compatibility
Providers differ in support for `response_format: {type:"json_object"}`. If unsupported, adjust the request payload for that provider. This adapter currently supports Chat Completions-compatible APIs, not the distinct Responses API or provider-specific authentication schemes.
