# PARADOX LAB V0.9 — autonomous research workflow

V0.9 orchestrates seed challenge generation, deterministic oracle labels, repeated model trials, stable-error detection, model-guided minimization, and fresh verification of minimized cases.

## Safety and evidence
- The engine never embeds provider credentials or makes network calls itself. The caller supplies an adapter.
- A fixed adapter-call budget prevents unbounded testing.
- Only repeated identical error classes are candidates for minimization.
- A minimized finding is promoted only if a fresh verification run reproduces the same error class.
- Provider errors are not treated as model reasoning failures.
- Reports retain raw validated outcomes and explicitly state limits.

## Run
Load V0.6, V0.7, V0.8, then V0.9 in that order. Call ParadoxLab09.investigate(adapter, options). Export JSON with exportReport(result).

## Current limits
The included seed bank is small and hand-authored. The engine has no live provider integration, no calibrated confidence intervals, and no independent semantic audit of natural-language paraphrases. It evaluates structured classical Boolean constraints only.
