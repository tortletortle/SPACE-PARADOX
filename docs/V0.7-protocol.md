# PARADOX LAB V0.7

## New capability: metamorphic variants
Generate logically equivalent rewrites (double negation, De Morgan, commutativity, implication elimination). Every rewrite is checked exhaustively over all assignments before it is emitted. This provides controlled paraphrase/structure variants without changing the formal answer.

## Counterexample minimization
The reducer uses a caller-supplied asynchronous predicate, typically "does the target model still make the same validated error?". It first replaces constraints with tautologies, then simplifies expression subtrees. The variable universe remains fixed, so rule indices and references remain stable. The result is 1-minimal under the implemented deletion/simplification operators, not globally minimum.

## Experimental protocol
- Freeze model identifier/version, prompt template, decoding parameters and retry policy.
- Run baseline and metamorphic variants in randomized order.
- Validate all outputs with V0.6 oracle.
- Repeat each item; report per-item stability and per-family error rate.
- Minimize only failures reproduced at least twice; rerun the minimized item and its parent.
- Keep raw outputs, timestamps, latency, token usage and adapter errors separate.

## Limitations
No live model API is included. The reducer requires an external adapter predicate. Equivalent Boolean rewrites do not guarantee equivalent natural-language interpretations; therefore use structured rule payloads and identical semantic instructions. Current expression equivalence checking is exhaustive and intended for small systems.
